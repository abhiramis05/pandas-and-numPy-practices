# pandas-and-numPy-practices


This repository contains Python practice and exercises using **NumPy** and **Pandas**. It covers fundamental concepts of numerical computing, data manipulation, data analysis, and working with structured datasets.

## Topics Covered

* NumPy arrays and operations
* Array indexing and slicing
* Mathematical and statistical operations
* Pandas Series and DataFrames
* Data selection and filtering
* Data manipulation and analysis
* Handling and exploring datasets

## Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

## Purpose

The purpose of this project is to build a strong foundation in NumPy and Pandas, which are essential libraries for **Data Science and Data Analysis**.
